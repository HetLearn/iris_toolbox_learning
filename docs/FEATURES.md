# hetlearn feature register

Every user-facing feature, where it is set, and where it came from.
**Origin:** `asked` = in the original brief; `ADDED` = added during the build (flagged for review).
**Where:** `model file` = IRIS `!if` toggle in the generated model; `master` = `config/master_options.m`;
`scenario` = scenario file; `spec` = `models/<name>/model_spec.m`.
**Status:** `spec` = specified, not yet built; `built` = built and covered by `tests/run_tests.m`;
`built (part)` = the toolbox function/option exists, the engine part is not built yet.
